📖 Panduan Ringkas — Signal → Grid Bot Pionex (SOP v8)
  1. Scan dan tunggu senarai signal. Fokus pada gred A+ (skor ≥6.5/8.5 + sweep + derivatif setuju) atau A (skor ≥5.0 + sweep). Gred B (≥3.5) = kurangkan saiz. Blacklist = JANGAN sentuh. v8: gred berpemberat bukti — sweep ×2.0, FVG ×1.5, BOS/CHoCH ×1.5, HTF ×1.0, zon ×1.0, displacement ×1.0, OB ×0.5; tiada sweep = maksimum B.
  2. Jenis grid: Signal LONG → Long Grid (bawah = SL struktur, atas = TP2). Signal SHORT → Short Grid (futures). Regime RANGE tanpa arah → tiada signal, tunggu.
  3. Masukkan parameter yang dipaparkan pada kad: Range Bawah / Range Atas / Bil. Grid. Jarak grid telah dikira supaya > 2× fee (≈0.1% round-trip) — bawah nilai itu, bot rugi walau "menang".
  4. Stop Loss bot: set stop-bot pada harga SL kad (bawah range untuk Long Grid). Jangan biar grid tanpa lantai.
  5. Leverage ikut cadangan kad (1–3×). Regime CHAOS/volatiliti melampau = automatik blacklist.
  6. Sesi: keutamaan London/NY & overlap. Asia = range/akumulasi, elak deploy grid arah baru.
  7. Keluar (v8): untuk signal manual — alih SL ke breakeven selepas +1R (harga trigger dipapar pada kad), tutup 50% di TP1, baki 50% lari ke TP2 dengan SL di BE. Untuk grid bot: harga tutup melepasi range atas (ambil untung, redeploy lebih tinggi jika trend berterusan) atau sentuh SL (henti, tunggu setup baru). Auto-scan 90s membantu pantau.
  8. v7 — Derivatif: chips baris kedua pada kad = FUNDING / OI / TAKER dari Binance Futures. LONG paling kuat bila funding ≤ 0, OI naik, taker > 1. Funding melampau (>|0.1%|) = auto-blacklist (risiko squeeze).
  9. v7 — Protections: pair yang baru tamat trade masuk cooldown 4 jam (tiada signal baru). Jika 3 SL dalam 24 jam → mod defensif: hanya A+ dibenarkan.
  10. v7 — CHoCH: chip "CHoCH" menggantikan BOS bila pecahan struktur itu pembalikan arah (isyarat terawal trend baru) — setup CHoCH + sweep + discount ialah antara yang terbaik.
  11. v8 — Exit Engine: jurnal & backtest guna peraturan exit yang sama (BE @+1R, 50% @ TP1). Status BE = scratch 0R (diselamatkan dari SL); TP1+BE = +1.0R; TP1+TP2 = +2.75R. Lajur MAE/MFE merekod ekskursi setiap trade untuk kalibrasi SL/TP.
  12. v8 — TP2 likuiditi: TP2 dihadkan pada pool likuiditi terdekat (equal highs/lows, atau high/low 50-candle HTF) — label "liq🎯" pada kad. Jika tiada ruang 2R ke pool, signal disekat (status matriks "TP2 disekat likuiditi").
  13. v8 — Trigger: ADX mesti menaik (tanda ↑ pada kad) untuk semua signal — memotong whipsaw Supertrend dalam pasaran chop. Entry basi tanpa sweep/displacement kebanyakannya tersingkir oleh tapisan ini.
