01 — Apa Ini?

GridBot Signal v4 adalah scanner real-time untuk 50 pasangan crypto di Binance. Dashboard ini membuat keputusan untuk kau — bukan sediakan data untuk kau analisa. Dalam masa 3 saat, kau patut tahu sama ada nak masuk trade atau tidak.

⚡

Prinsip utama: Buka dashboard → Tengok Top 3 signals → Baca Action Badge → Masuk atau skip. Itu sahaja.

02 — Cara Mula

1
Pilih Timeframe
Klik 15M / 1H / 4H di bar atas. Default: 1H. Untuk swing trade → pakai 4H. Untuk scalp intraday → 15M.
2
Set Min Probability
Default 60% — sesuai untuk kebanyakan situasi. Naikkan ke 70% jika pasaran volatile. Turunkan ke 50% jika nak lebih banyak signal (tapi kualiti lebih rendah).
3
Tekan SCAN
Dashboard akan scan 50 pasangan satu persatu. Ambil masa ~2 minit. Auto Rescan aktif setiap 90 saat secara default — biarkan ia berjalan.
4
Baca Command Panel (bahagian atas)
Tiga blok: Market Regime, Market Bias, dan Session Summary. Ini memberi konteks pasaran sebelum tengok signal.
5
Fokus ke Top 3 Signals
Signal di-rank mengikut Priority Score — yang paling berkualiti di atas. Baca Action Badge, Decision Line, dan Confidence Level. Ambil keputusan.

03 — Signal Class

Setiap signal diklasifikasikan secara automatik berdasarkan probability, HTF alignment, momentum, dan regime.

Class Maksud Syarat Saiz Trade
A+ Terbaik — Full Size Prob ≥72% + HTF aligned + Momentum accel + Regime fit 100% normal size
A Baik — Normal Prob ≥65% + Tiada HTF conflict + Regime fit 75–100% normal size
B Sederhana — Kurangkan Prob ≥55% + HTF aligned atau momentum kuat 40–60% normal size
C Lemah — Optional Memenuhi threshold minimum sahaja 20–30% atau langkau
💡

Jika kau baharu — hanya masuk signal A+ dan A sahaja. Ignore B dan C sepenuhnya.

04 — Action Badge (Jawapan Utama)

Ini adalah jawapan kepada soalan: patut masuk tak? Setiap signal card ada satu daripada tiga badge ini:

BadgeMaksudTindakan
✅ EXECUTE Signal kuat, syarat dipenuhi Masuk trade dengan saiz penuh atau hampir penuh
⚠ REDUCE SIZE Signal ada tapi ada kelemahan Masuk dengan saiz separuh atau kurang
❌ SKIP Signal tidak cukup kuat Jangan masuk. Tunggu signal lain.

05 — Confidence Level

Confidence dikira dari probability + score + context. Ini bukan sama dengan Probability % — ia lebih holistik.

Level
  • 🔥 EXTREME Semua faktor sejajar sempurna
  • 🟢 HIGH Majoriti faktor positif
  • 🟡 MEDIUM Faktor bercampur
  • 🔴 LOW Berisiko, kebanyakan lemah
Kombinasi Ideal
  • A+ + 🔥 EXTREME → Trade penuh, RR tinggi
  • A + 🟢 HIGH → Trade normal, confident
  • B + 🟡 MEDIUM → Separuh saiz, SL ketat
  • C + 🔴 LOW → Skip. Tunggu setup lain.

06 — Signal Status

Setiap signal mempunyai "umur" — masuk terlambat adalah satu risiko tersendiri.

StatusMaksudApa Patut Buat
🟢 FRESH Signal baru terbentuk (≤4 bar) Entry paling baik. Harga masih hampir entry point.
🟡 ACTIVE Signal masih valid (5–12 bar) Boleh masuk tapi semak jarak dari entry. Jangan kejar harga.
🔴 LATE Signal dah lama (>12 bar) Jangan masuk. Tunggu scan baru atau signal FRESH.

⚠ Jangan sekali-kali masuk signal status LATE. Harga kemungkinan besar dah jauh dari entry ideal — risiko tinggi, reward rendah.

07 — Core Factors (4 Ikon Utama)

Empat faktor ini ditunjukkan secara visual pada setiap card. Warna cerah = aktif. Warna gelap = tidak aktif atau neutral.

FaktorApa IaKenapa Penting
⬆ HTF ALIGNED Higher Timeframe (4H/1D) searah dengan signal Faktor paling penting. HTF aligned = trend lebih kuat. HTF conflict = elak masuk.
⚡ MOM ACCEL Momentum MACD sedang memecut (accelerating) Tenaga masih ada untuk meneruskan pergerakan. Jika WEAK, pergerakan mungkin akan slowdown.
💧 LIQ SWEEP Berlaku Liquidity Sweep (stop hunt) sebelum signal Tanda smart money telah "collect" order. Setup lebih reliable bila ada sweep.
⧖ BOS FRESH Break of Structure baru berlaku Konfirmasi perubahan atau penerusan struktur market. BOS fresh = momentum baru.

08 — Market Regimes

Dashboard detect 6 regime pasaran secara automatik. Regime menentukan jenis setup yang sesuai dan mode grid yang dicadangkan.

RegimeKeadaan PasaranMode TerbaikSignal Kualiti
TREND EXP Trend kuat sedang berkembang, ADX tinggi + ATR expanding Directional Grid Sangat tinggi
MATURE Trend matang, ADX >25, Bollinger lebar Directional Grid Tinggi
ROTATION Range / sideways, ADX rendah Grid Bot Sederhana
SQUEEZE Volatility sangat rendah, coil sebelum breakout Grid Bot / Tunggu Sederhana — tunggu breakout
CHAOS Volatility melampau, Bollinger sangat lebar AVOID Berbahaya — skip
REVERSAL Transisi dari trend ke range atau sebaliknya Swing / Selective Sederhana-tinggi
🚫

Jika CHAOS ditunjukkan sebagai dominant regime, jangan trade walaupun ada signal A+. Tunggu regime berubah.

10 — Entry / SL / TP

Setiap signal card sediakan tiga paras utama:

Paras Harga
  • ENTRY — Harga semasa (close candle terkini)
  • STOP LOSS — Berdasarkan ATR × multiplier
  • TP1 — Target pertama (ATR × 2.0)
  • TP2 — Target extended (ATR × 3.5)
Risk/Reward
  • RR ditunjukkan sebagai 1:X format
  • RR ≥ 1:2 = minimum acceptable
  • RR ≥ 1:3 = setup berkualiti tinggi
  • Partial close di TP1, biarkan balance ke TP2
ℹ

Paras ini adalah cadangan automatik berdasarkan ATR (Average True Range). Untuk pasaran yang sangat aktif, pertimbangkan adjust SL sedikit lebih longgar.

11 — Mode yang Dicadangkan

Dashboard cadangkan mod operasi berdasarkan regime semasa:

ModeBila DigunakanCiri
Directional Grid Regime: TREND EXP / MATURE + Bias BULLISH/BEARISH Grid dibuat mengikut arah trend. Range lebih sempit di satu arah.
Grid Bot Regime: ROTATION / SQUEEZE Grid neutral dua arah. Profit dari swing dalam range.
Swing Regime: REVERSAL / Bias neutral Trade manual mengikut signal. Bukan grid.

12 — Scanner Table (Bahagian Bawah)

Table ini tunjukkan semua 50 pasangan selepas scan. Berguna untuk:

  • Tengok pasangan mana ada signal tapi tak masuk Top 3
  • Semak Class, Prob, dan Action sekilas pandang
  • Monitor regime individual setiap pasangan
  • Harga live (updated via WebSocket)

Kolum ACTION dalam table papar ringkasan: ✅ GO / ⚠ REDUCE / ❌ SKIP.

13 — Settings & Controls

SettingDefaultBila Nak Ubah

Min Prob 60% Naikkan ke 70% bila market volatile. Turunkan ke 55% bila market sepi untuk dapatkan lebih signal.

14 — Buat & Jangan Buat

✅ Buat
  • Fokus ke Top 3 signal sahaja
  • Semak regime sebelum ambil keputusan
  • Ikut Action Badge — jangan override
  • Masuk hanya signal FRESH atau ACTIVE
  • Kurangkan saiz untuk signal B
  • Biarkan Auto Rescan berjalan
  • Klik "Details Lanjut" untuk lebih maklumat jika perlu
❌ Jangan
  • Masuk signal LATE status
  • Trade waktu CHAOS regime
  • Ignore HTF CONFLICT warning
  • Masuk semua signal serentak
  • Override SKIP badge dengan judgment sendiri
  • Jangan kejar harga jika dah jauh dari entry
  • Buka "Details" sambil market bergerak — keputusan lambat

15 — Quick Reference

Kombinasi Signal Terbaik
  • A+ · ✅ EXECUTE · 🔥 EXTREME · 🟢 FRESH
  • A · ✅ EXECUTE · 🟢 HIGH · 🟢 FRESH
  • A+ · HTF ALIGNED · MOM ACCEL · BOS FRESH
  • TREND EXP regime · Directional Grid mode
Red Flags — Elak Terus
  • CHAOS regime (warna merah di Command Panel)
  • Status LATE pada mana-mana signal
  • HTF CONFLICT tapi nak masuk juga
  • Class C + Confidence LOW
Saiz Trade (Guideline)
  • A+ → 100% normal size
  • A → 75–100% normal size
  • B → 40–60% normal size
  • C → 20% atau langkau
Mode Grid Pilihan
  • TREND EXP/MATURE → Directional Grid
  • ROTATION/SQUEEZE → Grid Bot
  • REVERSAL → Swing manual
  • CHAOS → Tiada trade
